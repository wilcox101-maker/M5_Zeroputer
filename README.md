# M5_Zeroputer
M5 Zeroputer fuses the M5Stack Cardputer Adv ESP32-S3 and RP2040 Zero into a true hybrid system:  - Cardputer Adv: User interface, display, keyboard, audio playback + recording, SD storage, WiFi/BLE, battery. - RP2040 Zero: real-time PIO engine, extra GPIO, deterministic control.  Comms using robust UART control plane +SPI high-bandwidth data plane
